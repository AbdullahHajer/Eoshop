## 1. الهدف

إغلاق فجوة صغيرة مثبتة في محرر المساحات التسويقية لقالب Elegant: العقد والخادم والواجهة العامة كانت تدعم `backgroundColor` و`textColor` لكل قصة، لكن التاجر لم يكن يستطيع تعديل القيمتين أو معاينة النتيجة من لوحة تخصيص المتجر.

## 2. المنجز

- تحكم مستقل بلون الخلفية ولون النص لكل قصة باستخدام منتقي لون أو قيمة `#RRGGBB`.
- معاينة فورية للصورة والنص والشارة والزر مع focal point وطبقة التعتيم الحالية.
- إظهار نسبة تباين اللون الاحتياطي وتنبيه واضح عندما تقل عن `4.5:1`.
- زر يختار تلقائيًا لون النص الأبيض أو الأسود الأعلى تباينًا.
- إبقاء الألوان ضمن عقد `marketingBlocks` الحالي ومسار الحفظ Revisioned الموجود.
- اختبار يغطي استقلال ألوان القصة، المعاينة، التحذير والاختيار التلقائي.

## 3. الحدود

- لا API أو endpoint أو Migration أو جدول أو dependency جديد.
