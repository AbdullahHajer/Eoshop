## الهدف

إغلاق رحلة الزائر في قالب Elegant بصفحتين واضحتين لـ«عن المتجر» و«التواصل» وتذييل تحريري متسق مع القالب، مع عرض بيانات المتجر المحفوظة فقط وإبقاء الروابط والتنقلات الحالية حقيقية وقابلة للاستخدام.

## داخل النطاق

- تركيب بصري مستقل لصفحة «عن المتجر» يستعمل العنوان والنبذة والرؤية والصورة المنشورة الحالية.
- تركيب بصري مستقل لصفحة «التواصل» يستعمل الهاتف وWhatsApp والبريد والعنوان وساعات العمل والحسابات المنشورة الحالية.
- تذييل Elegant مستقل بصريًا مع روابط تنقل حقيقية وحالات فارغة صادقة.
- المحافظة على التباين الديناميكي، RTL، الجوال، لوحة المفاتيح والحركة المخفّضة.
- نماذج مراجعة محلية لصفحتي «عن المتجر» و«التواصل» على سطح المكتب والجوال.

## خارج النطاق

- لا API أو Migration أو Database أو عقد خادمي أو dependency جديدة.
- لا نموذج رسائل داخل المنصة ولا وعود بزمن استجابة أو شحن غير محفوظة.
- لا تعديل لتصميم Tech Bento أو عقد كتل التسويق الذي يعمل عليه المطور الآخر.
- لا Push أو PR أو Merge قبل اكتمال التنفيذ والاختبارات والمراجعة البصرية.

## معايير القبول

- يظهر اختلاف Elegant بصريًا في الصفحتين والتذييل، ولا يكون مجرد تبديل ألوان للواجهة المشتركة.
- لا تظهر أرقام أو عناوين أو حسابات أو وعود افتراضية عند غيابها.
- كل رابط هاتف وWhatsApp وبريد وحساب اجتماعي صالح فقط، ولا توجد روابط `#` أو وجهات وهمية.
- تبقى بيانات «عن المتجر» و«التواصل» من `StoreConfig` الحالي دون نسخة حالة أو مصدر بيانات جديد.
- يبقى قالب Tech على المكونات الحالية دون أصناف أو تركيب Elegant.
- تنجح الاختبارات المركزة ومجموعة Frontend الكاملة وTypeScript والبناء و`git diff --check`.

## المخاطر والضوابط

- **اختلاق محتوى تسويقي:** تستخدم الحالات الفارغة نصًا صريحًا بدل قيم توضيحية أو وعود غير مثبتة.
- **تكرار تنظيف الروابط:** تبقى قواعد الهاتف وWhatsApp الحالية، وتُوحّد وجهات الحسابات الاجتماعية بين صفحة التواصل والتذييل.
- **تأثر Tech:** يختار `StorePreview` مكونات Elegant فقط عند `themeStyle=elegant`.
- **ضعف التباين مع ألوان التاجر:** تحسب ألوان النص لكل سطح ديناميكي بدل افتراض لوحة ثابتة.

## الأدلة

### المنجز

- صفحة «عن المتجر» تحريرية مستقلة لقالب Elegant تستعمل العنوان والنبذة والرؤية والصورة والعنوان وساعات العمل المحفوظة.
- صفحة تواصل تحريرية تستعمل وجهات الهاتف وWhatsApp والبريد والحسابات الصالحة فقط، مع حالات فارغة صريحة.
- تذييل Elegant مستقل بصريًا مع تنقلات حقيقية وتباين ديناميكي؛ بقي تذييل Tech السابق دون تعديل بصري.
- توحيد بناء روابط الحسابات الاجتماعية بين صفحة التواصل والتذييل لمنع اختلاف التحقق بين السطحين.
- تصحيح حالة تنقل صفحة التواصل حتى لا تظهر «الرئيسية» كصفحة نشطة بصورة خاطئة.
- لا API أو Migration أو Database أو dependencies جديدة.
