1. ملخص القرارات والتعديلات المعمارية التي تم الاتفاق عليها

تم تحويل المشروع من نموذج أولي يعتمد كلياً على التخزين المحلي لمتصفح العميل (Client LocalStorage) إلى منصة SaaS متكاملة وجاهزة للعمل على خوادم الـ VPS بحسب المتطلبات التالية:

المجال الوضع التجريبي السابق الوضع المعماري النهائي المعتمد
إطار العمل لخادم الخلفية Express.js بسيط في `server.ts` Laravel 11 (PHP 8.4) API متكامل مع حزمة `stancl/tenancy` v3
قواعد البيانات والعزل `localStorage` في متصفح العميل PostgreSQL 16 + Database-per-Tenant (قاعدة بيانات معزولة كلياً لكل متجر)
النطاقات الفرعية (Subdomains) غير موجودة توجيه آلي عبر Nginx و Stancl Tenancy (`subdomain.domain.com`)
توليد الذكاء الاصطناعي مباشر من Node.js SDK خدمة مخصصة بـ Laravel (`GeminiStoreGeneratorService`) متصلة بـ Gemini API
بيئة التشغيل والنشر تشغيل فردي Docker Compose موحد بـ 4 حاويات (Nginx, PHP 8.4, PostgreSQL 16, PgBouncer)

2. معمارية قواعد البيانات وعزل المتاجر (Database Schemas)

أ. قاعدة بيانات المنصة المركزية (`platform_main`)

تحتوي على جداول التحكم والإدارة المركزية:

  • `tenants`: قائمة المتاجر، أسماء المالكين، حالة التوثيق (مقبول، معلق، مرفوض)، وهيكل الهوية.
  • `domains`: النطاقات الفرعية (`subdomains`) والنطاقات المخصصة المربوطة بكافة المتاجر.
ب. قاعدة بيانات المتجر الفردية (`tenant_store_...`)

تنشأ وتطبق عليها الميغريشن تلقائياً عند تسجيل كل متجر جديد:

  • `store_configs`: إعدادات المتجر الهيكلية، الألوان، الخطوط، طرق الدفع المحلية، والبوات الإلكترونية.
  • `products`: المنتجات، كميات المخزون SKU، التصنيفات، والأسعار بالريال السعودي.
  • `orders`: طلبات الشراء، بيانات العملاء، حالة الدفع والشحن.

3. دليل التشغيل المحلي والرفع على خادم الـ VPS خطوة بخطوة

أولاً: التشغيل المحلي على جهازك (Local Development)

لبناء وتحديث البيئة محلياً، قم بتشغيل الأوامر التالية في Terminal:

docker compose up -d docker compose exec backend php artisan migrate --path=database/migrations/system

رابط المعاينة المحلي: http://localhost:8000

ثانياً: النشر والرفع الإنتاجي على سيرفر الـ VPS (Production VPS Deployment)

عند تجهيز سيرفر الـ VPS الخارجي:

  1. قم بإضافة سجل A-Record في النطاق الخاص بك ليأشر كـ Wildcard: `*.yourdomain.com -> IP_VPS`.
  2. قم بسحب الكود وإضافة المفاتيح في ملف `backend/.env`.
  3. قم بتشغيل الحاويات وتطبيق الميغريشن بأمر واحد:
    docker compose up -d --build docker compose exec backend php artisan migrate --path=database/migrations/system

4. دليل الملفات الهيكلية الرئيسية في المشروع

الملف / المجلد الوصف والوظيفة
docker-compose.yml الملف الرئيسي لتنسيق وتشغيل حاويات النظام (PHP 8.4, Nginx, Postgres, PgBouncer).
docker/nginx/default.conf إعدادات خادم Nginx لتوجيه الـ Subdomains والـ APIs والفرونت إند.
GeminiStoreGeneratorService.php خدمة الاستدعاء المباشر لـ Google Gemini API لتوليد المتاجر بالذكاء الاصطناعي.
TenantController.php إدارة إنشاء المتاجر المعزولة ولائحة الأدمن للموافقة أو الرفض والإيقاف.
config/tenancy.php إعدادات حزمة stancl/tenancy وإنشاء قواعد البيانات الديناميكية `tenant_...`.
